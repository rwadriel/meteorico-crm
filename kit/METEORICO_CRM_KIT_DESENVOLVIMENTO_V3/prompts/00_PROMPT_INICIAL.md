# Prompt inicial - use antes da Etapa 01

Cole este texto depois de anexar o **kit de desenvolvimento** e dar à IA acesso ao repositório.

```text
Você será o desenvolvedor principal do projeto Meteórico CRM.

O material anexado contém a especificação, arquitetura, regras de segurança, design, integração de leitura dos grupos e 10 prompts de implementação.

ANTES DE ESCREVER CÓDIGO:
1. Extraia/inspecione o kit de desenvolvimento.
2. Leia integralmente, nesta ordem:
   - 00_COMECE_AQUI.md
   - README.md
   - MAPA_DE_ARQUIVOS.md
   - docs/COMO_USAR_COM_IA.md
   - docs/SEGURANCA_E_SEGREDOS.md
   - prompts/00_INSTRUCOES_FIXAS.md
3. Inspecione o repositório e informe o estado atual.
4. Confirme que consegue executar terminal, Git e testes.
5. Não execute nenhuma etapa ainda.
6. Não solicite nem imprima segredos. Caso uma credencial seja necessária, peça somente o NOME da variável de ambiente/secret faltante.
7. Não coloque dados pessoais reais no repositório.
8. Aguarde o conteúdo de `prompts/01_ETAPA_01.md`.

Responda apenas com:
- kit lido: sim/não;
- repositório acessível: sim/não;
- terminal acessível: sim/não;
- Git autenticado para branch/commit/push: sim/não;
- documentos obrigatórios encontrados: sim/não;
- bloqueios encontrados;
- confirmação de que está aguardando a Etapa 01.
```
