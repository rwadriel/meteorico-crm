# Checklist do proprietário antes de iniciar

## Obrigatório para a Etapa 1

- [ ] Repositório GitHub criado.
- [ ] A IA consegue clonar, criar branch, commitar e fazer push.
- [ ] O acesso ao GitHub foi entregue como integração ou secret, nunca no prompt.
- [ ] `README.md` e este pacote estão disponíveis para a IA.
- [ ] A referência visual do dashboard está disponível.
- [ ] O kit da API do WhatsApp Manager está disponível.
- [ ] Fuso confirmado: `America/Belem`.
- [ ] Nome do projeto confirmado: `meteorico-crm`.

## Pode ficar para etapas posteriores

- [ ] Documentação do provedor oficial de mensagens privadas do WhatsApp.
- [ ] Documentação e amostras anonimizadas da API de participações.
- [ ] Credenciais da Eduzz configuradas como secret.
- [ ] Chave xAI/Grok configurada como secret.
- [ ] Domínios de staging e produção.
- [ ] Links dos grupos de cada campanha.
- [ ] Textos finais das mensagens e botões.
- [ ] Logotipo e ativos finais.

## Não prossiga quando

- a IA disser que os testes passaram sem mostrar os comandos e resultados;
- houver token em arquivo, log ou commit;
- a etapa anterior tiver falhas abertas críticas;
- a IA tiver implementado itens de etapas futuras de forma improvisada;
- não existir `docs/PROJECT_STATE.md` atualizado.
